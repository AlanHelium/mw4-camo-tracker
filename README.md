# MW4 迷彩猎手 / MW4 Camo Tracker

Windows 独立迷彩计划工具。选好今天刷的武器，游戏中用小窗看目标，局后统一更新进度。

[下载 v0.7.1 试用版](https://github.com/AlanHelium/mw4-camo-tracker/releases/tag/v0.7.1) · [提交问题](https://github.com/AlanHelium/mw4-camo-tracker/issues)

![主界面与游戏小窗](docs/interface.png)

主界面顶部「设计」可切换原版与 3 个新布局，切换不改变挑战进度，小窗同步强调色与圆角。原版仍为首次升级默认。

## 开始使用

1. 下载 Windows x64 压缩包，解压后运行 `CamoTracker.exe`。免安装，无需另装 .NET。
2. 在「已解锁清单」勾选已经拥有的迷彩。军用迷彩按游戏实际已解锁确认，无需填写普通武器等级；巅峰路线另记巅峰状态。
3. 勾选今天刷的武器，最多 5 把。未制定计划时，默认推荐 5 把。
4. 选中一把武器，点「游戏小窗」。小窗只显示当前这把枪及目标迷彩，点「切枪」更换；局后确认已解锁，计数任务可直接在小窗填游戏内总数。

运行包中的 `打开游戏小窗.cmd` 可直达小窗。建议搭配无边框窗口；独占全屏置顶和游戏内热键接收仍需实机验证。

## 资料更新

「··· → 资料更新 → 检查更新」，查看新增武器、挑战和条件调整，再点击安装。支持武器中英文名、枪图、迷彩图、任务条件、等级、巅峰和全局门槛独立更新；无需每次重新下载整个 APP。正常使用不联网轮询，也不上传进度。GitHub 接口限流或连接失败时可自动使用同仓库 CDN 通道。

无法访问 GitHub 时，可从 Releases 下载 `catalog-pack.zip`，在同一页面导入离线包。更新前自动备份，保留已有进度、今日计划和用户自定义内容。全新程序功能或规则运算仍需升级 APP。资料仍由维护者核实后发布，未公开条件不会自动变成已确认数据。

## 功能

- 主界面与小窗共用深色视觉；可选酸橙绿、冷蓝、暖橙，特殊、完成主义、巅峰路线保留辅助色。
- 主界面保留最多 5 把今日计划；小窗只展示当前这把枪及目标迷彩，支持直接切枪。确认完成后接续同一把枪的下一目标；优先推荐已知前置满足、接近完成的目标，也可指定「本局冲这个」。
- 主界面「全局进度」可查看收集率、路线剩余百分比、最近可完成目标，以及全部武器的军事/特殊/黄金/白金/赤律/巅峰进度；支持分类筛选与中文搜索。
- 历史解锁清单、前置条件、武器巅峰门槛；未知进度不会当成 0。
- 33 把武器逐一对应官方原厂枪型；列表、小窗、历史清单显示正确的枪型缩略图。小窗大图显示目标迷彩的官方样式参考，并明确标注参考枪身。
- 主界面、小窗、清单直接显示官方简中武器名和英文名，例如「阿克西恩 / Axion」「威尔46 / VEL 46」「玄铁（点射型）/ Hyeon Burst」；支持中文搜索。M4 等官方沿用的型号保留原名。
- 99 项特殊迷彩中文参考翻译与英文原名；军事、完成主义、巅峰与模式精通名称、条件也有英文对照。
- 18 种官方静态外观参考，可查看原图；缺少确切图片的项目显示类别标识。
- 确认解锁时播放约 2.5 秒原创奖杯提示，可关闭动画；0.92 秒原创合成成就音效，默认静音，可独立启用或试听。支持菜单预览，批量补历史不刷屏，遵循 Windows 关闭动画设置。
- 置顶、拖动、透明度、大小、鼠标穿透；自动保存、撤销、JSON 导入导出。
- 作者提供的原始赞赏码，全部功能免费。

原厂枪型与迷彩参考分开展示。迷彩参考图中的示例枪身为 HAN 86，不会把它伪装成其他武器的涂装。配图不是 PBR 材质、实时 3D 枪模或动态迷彩，尚未覆盖全部迷彩图片。

全局收集率按本地已解锁项目数计算，路线按已解锁武器/项目数计算；单项任务百分比按已录入数值计算。未录入进度显示未知，最近目标排除前置未满足或要求待核对的项目。百分比不是击杀耗时估算，也不会自动同步游戏账号。

## 武器路线与前置

点主界面「武器路线」，或小窗「全部路线」，可查看带图片的长节点路线、当前任务及前置；巅峰显示为独立分支。主界面与小窗的计数任务均检查已知前置，白金需要同类别黄金；小窗逐条显示已完成数量与还差几把，未满足时禁用完成操作。军用迷彩的具体前置原文尚待逐项核实，仅提供「游戏里已解锁」来确认实际拥有状态，不把共享配件数量换算成等级，也不按参考等级自动解锁。历史清单用于补录实际已拥有的皮肤，不把补录当成本局完成。

「校正到此节点」可把当前武器的一条路线恢复到指定里程碑：确认后补齐该节点及前面项目、清空后面项目，另一分支及其他枪保留，可撤销。特殊迷彩可独立刷取，校正属于批量历史操作，不表示它们必须按顺序完成。枪图角标展示已拥有的迷彩样式参考和路线条；缺少官方确切配图时明确留空，不生成假涂装。

## 操作

不要求逐个记录击杀。局后填总进度或勾选已解锁。单局、连杀等挑战以游戏内确认的完成次数为准，击杀数不等于挑战完成次数。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl + Alt + Enter | 标记当前迷彩已解锁 |
| Ctrl + Alt + 1～5 | 切换今日计划 / 推荐目标 |
| Ctrl + Alt + Z | 撤销 |
| Ctrl + Alt + M | 切换主界面与小窗 |
| Ctrl + Alt + Space | 隐藏 / 显示 |
| Ctrl + Alt + L | 锁定小窗、鼠标穿透 |

L 被占用时尝试 Ctrl + Alt + F8，以界面显示为准。解锁热键不可用时禁止启用穿透。对话框打开时暂停处理热键。

存档：`%LOCALAPPDATA%\CamoTracker\progress.json`。保存时保留 `.bak`，旧版数据升级前另留迁移备份。

## 数据范围

2026-10-23 整理：33 把武器，每把 8 项军事、3 项特殊、3 项完成主义条件，另列武器巅峰和模式精通路线。条件主要来自公开社区资料，**不是逐项实机核验的官方完整数据库**。缺失、冲突和开放等级未知的项目会显示待核对，详情保留来源与可用的 DMZ 条件参考。

武器巅峰（俗称武器转生）与玩家巅峰不同。Pyroclast 对应武器巅峰 1 级；Terminus 对应该轮满级；Scatter / Cascade 对应武器巅峰大师 150 / 250 级。进入巅峰不会一次开放全部巅峰迷彩。

多人条件用于推荐；DMZ 文字供对照，不自动换算跨模式进度。账号与真实解锁状态需手动确认。详见 [数据来源与边界](docs/DATA.md)。

## 性能与游戏配合

不截取游戏画面、不读游戏内存、不注入、不使用驱动，不连接游戏账号。正常使用时无联网下载、游戏进程扫描或定时刷新，资料页仅在点击检查时联网；界面在操作时更新，图片静态缓存且枪型解码缓存最多 8 张。解锁动画仅在确认解锁后短暂运行，结束即销毁；路线操作仅有短暂过渡，空闲时没有持续动画。仅注册系统全局快捷键。

[测试记录](docs/VALIDATION.md) 包含本机待机占用。尚无游戏帧率对照实测，不能承诺零性能影响或所有游戏环境兼容。

默认输入兼容模式支持数字、英文与中文粘贴；正常中文 IME 可用 `CamoTracker.exe --system-ime` 启动。当前电脑系统 TSF 曾导致 WPF 挂起，因此默认只在本进程禁用 TSF，不改系统设置。

## 构建

Windows 10/11 x64，开发需 .NET 10 SDK，运行 `powershell -File scripts/build.ps1`。无第三方运行时依赖。

`--self-test` 执行模型验证；`--screenshot <绝对路径.png>` 使用隔离的内存演示数据验证并渲染界面，不读写用户存档。README 截图是演示进度。

条件整理脚本 `scripts/import-community-catalog.py` 需要 Python 与 `beautifulsoup4`；官方枪型整理脚本 `scripts/import-official-weapons.py` 另需 Pillow。只在维护时运行，结果应人工复核后提交，客户端不会自动抓取。
